Elpis
------

Elpis is a native Pandora Radio client for Linux. It descends from the
[Pithos](https://github.com/pithos/pithos) project (GPL-3.0) and adds a port
to GTK 4, a refreshed Flatpak runtime, and additional UI for managing
stations, bookmarks, and seeds from the desktop.

It's much more lightweight than the Pandora.com web client, and integrates
with desktop features such as media keys, notifications, and the sound menu.

For install instructions and more, see the
[Elpis home page](https://github.com/DavidMcFarlin/elpis).
