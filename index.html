Elpis

A native GTK 4 Pandora Radio client for the GNOME desktop — lightweight, keyboard-friendly, and fully integrated.

Install View on GitHub

Features

📻

Full Pandora playback

Stream any station, rate tracks, and skip — all the core Pandora controls you rely on.

🎛️

Station management

Create, delete, and edit stations. Add or remove song, artist, and genre seeds without leaving the app.

🔍

Genre browser

Discover new music through Pandora's built-in genre station catalog.

💡

Why is this playing?

One-click access to Pandora's track-explanation traits so you understand every recommendation.

🔖

Bookmarks

Bookmark songs and artists, then view and manage them in the dedicated bookmarks panel.

🎹

Media keys & MPRIS

Control playback from your keyboard or any MPRIS-compatible widget without switching windows.

🎸

Last.fm scrobbling

Automatically scrobble every track to your Last.fm profile via the integrated pylast backend.

🔔

Desktop notifications

Get a desktop notification on track change — album art and all — via the GNOME notification area.

🔒

Secure credentials

Account credentials are stored in the system keyring via libsecret — nothing written to disk in plaintext.

Install

Flatpak (recommended)

Build and install locally until Elpis lands on Flathub:

flatpak-builder --force-clean --user --install \
  --install-deps-from=flathub \
  build-flatpak flatpak/io.github.DavidMcFarlin.Elpis.json

flatpak run io.github.DavidMcFarlin.Elpis

From source

meson setup --prefix=$HOME/.local build
meson install -C build
glib-compile-schemas $HOME/.local/share/glib-2.0/schemas
elpis

Requirements: meson, ninja, GTK 4 ≥ 4.10, Python 3.10+, PyGObject, GStreamer 1.0, libsecret.
Optional: pylast for Last.fm scrobbling.

Releases

v1.6.3 2026-06-01

Initial Elpis release, descended from Pithos 1.6.2 with significant updates.

  • Port from GTK 3 to GTK 4
  • Bump Flatpak runtime to GNOME 50
  • Remove bundled internal-tuner CA certificate (expired 2020); TLS now validates against system trust store
  • Harden network error handling for modern Python URLError / TimeoutError types
  • Update bundled pylast from 2.2.0 to 4.5.0 and drop the obsolete six dependency
  • Add discoverable hamburger menu with quick "New Station" entry point
  • Add "Why is this playing?" explanation traits via track.explainTrack
  • Add genre station browser
  • Add station seed manager (add/remove song, artist, genre seeds)
  • Add station sharing via email
  • Add bookmarks viewer with delete
  • Add right-click context menu on stations dropdown with delete
v1.6.2 2024-03-03
  • Fix issue where playback would stop after a few songs
  • Fix album art caches never being deleted
v1.6.1 2023-05-19
  • Fix Python 3.11 support
  • Fix incorrectly labeling very short songs as ads
