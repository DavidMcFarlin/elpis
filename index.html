Pandora Radio, at home on GNOME.

A maintained fork of Pithos, rebuilt on GTK 4 and libadwaita — with the Pandora features upstream never shipped.

What it does

Everything the Pandora API offers, surfaced in a native desktop client — including the parts upstream Pithos never exposed.

Playback
Play, pause, skip, thumbs up and down, "tired of this song"
Stations
Switch, create, delete, and share stations
Discovery
Genre browser, station seed manager, "Why is this playing?"
Bookmarks
View and delete bookmarked songs and artists
Desktop
Media keys, MPRIS, track-change notifications, sound menu
Scrobbling
last.fm support
Sound
10-band equalizer plugin, screensaver pause and inhibit
Credentials
Stored in the system keyring via libsecret
Network
Proxy support
Themes
Light and dark, platform-native libadwaita

Install

Flatpak is the recommended path. The repo is self-hosted on GitHub Pages and signed with a maintainer GPG key, so flatpak install verifies each build automatically.

Elpis is too new to meet Flathub's submission bar — a Flathub listing will follow once the project qualifies.

flatpak
flatpak remote-add --if-not-exists elpis \
  https://davidmcfarlin.github.io/elpis/repo/
flatpak install elpis io.github.DavidMcFarlin.Elpis
flatpak run io.github.DavidMcFarlin.Elpis
from source
meson setup --prefix=$HOME/.local build
meson install -C build
glib-compile-schemas $HOME/.local/share/glib-2.0/schemas
elpis

Requires meson, ninja, GTK 4 ≥ 4.10, Python 3.10+, PyGObject, GStreamer 1.0, and libsecret. Optional: pylast for last.fm scrobbling.

The jar, and what stayed inside

In Greek mythology, Pandora opened a jar — in Greek, a pithos — and released all the evils into the world. Elpis, the spirit of Hope, was the only thing that remained inside. When development of the Pithos player stalled, this fork took the name of what was left in the jar and kept the music playing.

How is Elpis different from Pithos?

It modernizes the app for current Linux desktops: GTK 3 became GTK 4 with a platform-native libadwaita interface, the Flatpak runtime moved to GNOME 50, the expired internal CA certificate is gone, and network error handling was updated for modern Python. On top of that it adds a genre browser, a station seed manager, station sharing, a bookmarks viewer, one-click station creation, and "Why is this playing?" — features the Pandora API always had but the upstream UI never showed.

Will my Pithos settings migrate?

No. On first launch you sign in to Pandora again; credentials go to the system keyring via libsecret, so you enter them once.

Will changes flow back to Pithos?

Elpis is maintained independently. Upstream Pithos hasn't shipped a release since March 2024 — contributions there are still welcome on their own terms, but this project doesn't depend on review bandwidth from anyone else.

Hope was what stayed in the jar.
